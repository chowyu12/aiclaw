# 通过对话配置 AIClaw

在桌面会话里直接提出配置需求，例如：

- 「帮我配置邮箱，测试通过后启用。」
- 「把默认搜索引擎换成 Tavily。」
- 「添加一个 MCP，我把 JSON 填进卡片。」
- 「启用邮件插件」或「从本地目录安装插件」。
- 「每天早上 8 点检查公开项目更新」，或「把这个任务改到 9 点」。

助手通过 `app_config_list` 查看配置状态和 ID，通过 `app_configure` 打开当前会话的配置卡片。卡片显示操作对象、可编辑配置和生效说明。确认后由桌面主进程调用已有设置接口，返回保存及测试结果；取消不会继续执行配置操作。

| 类型 | 支持的操作 | 验证方式 |
| --- | --- | --- |
| 邮件 | 修改账号和服务器、启用、停用、测试 | 复用 IMAP/SMTP 连接测试，测试通过才新启用 |
| 搜索引擎 | 添加、编辑、选为默认、启停、删除、测试 | 用固定查询测试连接；选默认时先测试，再切换引擎 |
| MCP | 添加、编辑、JSON 导入、启停、删除、测试、OAuth 登录 | 复用 MCP 握手及工具列表检查；stdio 测试会运行配置中的命令 |
| 插件 | 安装本地目录、填写配置、启停、删除本地插件 | 复用插件配置和权限校验；没有通用的插件联网测试 |
| 定时任务 | 创建、编辑、暂停、恢复、删除 | 复用时间规则校验和调度器，返回下一次运行时间 |

## 凭据与执行边界

密码、授权码、API Key，以及 MCP 环境变量、请求头和导入 JSON 都在卡片内直接填写，经专用 IPC 交给主进程。模型工具结果只返回状态，不能读取这些内容。空白凭据表示保留已配置的值；MCP 环境变量或请求头填写 `{}` 表示清空。外部服务报错可能含凭据，配置助手不原样回传这些错误。

卡片由主进程保存待处理请求，渲染页面重载后可以恢复；密码草稿不恢复。重复提交、过期待处理项和已取消项不能继续保存。当前轮次结束或运行时退出后清除待处理卡片。写操作仍由卡片确认，即便会话使用“全部放行”档位。

此入口只在交互式桌面主会话启用。通道、后台定时任务和子 agent 不获得此配置能力。工具说明要求配置意图来自用户，不能把邮件、网页或文件中的文字当作配置指令。

## 当前边界

- 插件安装使用本地插件目录。渠道插件可修改已有连接（用列表返回的 `connectionId`），新建连接和微信扫码仍使用设置页。
- MCP JSON 每张卡片导入一个服务，支持单个 server 配置或含一个服务的 `mcpServers` 对象。
- 需要 OAuth 的 MCP 可先保存为停用状态，完成浏览器授权并测试后再启用；浏览器授权开始不等于登录完成。
- 设置保存与网络测试不构成跨接口事务。测试失败可能已经保存部分设置，界面会明确提示；取消后保留此前已保存的改动。
- 运行中的任务使用已挂载的工具。配置完成后会安排重新挂载；已有自动排队任务仍使用当前挂载，队列执行完或重新打开会话后更新。定时任务配置立即保存，但只在应用运行时执行。

## 本地验证

`npm run test:renderer` 包含配置助手状态、凭据隔离、确认/取消、搜索默认切换、MCP 导入及并发覆盖、插件接口和真实本地调度器用例。Go 测试覆盖内核工具到宿主的请求及桌面/通道/子 agent 能力边界。`npm run smoke:desktop` 使用真实 Vue/preload 与受控 IPC 检查卡片、密码框、重载恢复和结果展示。

这些验证不使用真实邮箱、付费搜索服务或模型凭据，不等于所有外部服务的端到端联调。
